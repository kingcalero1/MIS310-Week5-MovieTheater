## Week 5 In-Class Activity - Movie Theater Advertising

This was an in-class activity from Week 5.

The program calculates profit for a movie theater based on advertising spending. It compares different ad types (radio or internet) and estimates attendance and profit.

---

## What the program does

The user enters:
- Advertising cost
- Type of advertising (radio or internet)

The program then:
- Estimates how many people will attend
- Calculates ticket sales
- Subtracts fixed and advertising costs
- Outputs the final profit
